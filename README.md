# MDST Onboarding - F26 (Veer Mistry)

This repo contains my completed submission for the MDST F26 New Member Tutorial.

## Contents

- `tutorial0/` - Python/Pandas fundamentals tutorial + `checkpoint0.ipynb` (required, graded)
- `tutorial1/` - ML walkthrough tutorial + `checkpoint1.ipynb` (required, graded)
- `data/` - datasets used by the tutorials and checkpoints (`cereal.csv`, `starbucks.csv`, `states_edu.csv`)
- `requirements.txt` - Python dependencies needed to run the notebooks

Optional challenges (ML / DL / RvF) were not attempted for this submission.

## Setup

```bash
pip install -r requirements.txt
jupyter notebook
```

Then open `tutorial0/checkpoint0.ipynb` and `tutorial1/checkpoint1.ipynb` to work through the checkpoints.
